# Portfolio Integrity Statement

This repository is an **independent portfolio project**: a **simulated** security-control assessment of a **fictional organization**.

## What this project is

- A realistic simulation of governance, risk, and compliance (GRC) work: control selection, evidence evaluation, control testing, access certification, third-party risk assessment, risk analysis, POA&M management, remediation validation, and executive reporting.
- Built by Markese Raley as a self-directed portfolio exercise.
- Mapped to **NIST SP 800-53 Rev. 5 (Release 5.2.0)** and related NIST guidance, which was verified against NIST's website during the build (see [nist-800-53-strategy.md](docs/assessment/nist-800-53-strategy.md#1-standards-verification)).

## What this project is not

- **Not** an official government assessment, FedRAMP authorization, FISMA compliance determination, HIPAA compliance determination, SOC 2 examination, or certification of any organization.
- **Not** a formal audit. The author is not presenting this as work performed for an employer or client.
- **Not** based on any real organization's data. The author did not work for Wrenfield Health, Inc., which does not exist.

Real platforms (AWS, Okta, GitHub, Google Workspace) are named only to describe a plausible technology stack. **No statement in this repository describes the actual security, configuration, or attestations of any real company.** Every finding describes the fictional customer's own configuration under the shared-responsibility model.

## Data safety

No real PHI, personal data, credentials, keys, or proprietary information appear in this repository. Names are invented. Account identifiers, IP ranges (RFC 5737 documentation ranges), and ticket numbers are synthetic.

## Standards references

NIST publications are cited by number, revision, and date. Control titles follow SP 800-53 Rev. 5. Control *requirement summaries* are the author's paraphrases for readability. The authoritative text is the NIST catalog. HIPAA citations refer to 45 CFR Part 164 and are used to show traceability. They are not legal advice.
